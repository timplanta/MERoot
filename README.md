# MERoot

<!-- badges: start -->

<!-- badges: end -->

The goal of MERoot is to provide some simple open-source tools in R for
image and data analysis of confocal microscopy of plant roots. We
consulted our colleagues for what being truly useful to their research,
and based on our personal experiences, we created several custom
function that could accelerate the data analysis workflow, which could
be time-consuming if working manually with ImageJ.

## Installation

You can install the development version of MERoot from
[GitHub](https://github.com/) with:

``` r
# install.packages("pak")
pak::pak("timplanta/MERoot")
```
